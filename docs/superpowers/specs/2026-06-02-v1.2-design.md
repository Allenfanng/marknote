# MarkNote v1.2 Design Spec

## Overview

7 improvements for v1.2: file association fix, startup optimization, icon update, auto-save, word count, HTML/PDF export, sidebar.

## 1. File Association Fix

**Root cause:** OS opens .md file via association → file path passed as CLI arg, not URL param → frontend never receives it.

**Implementation:**
- `tauri.conf.json`: add `bundle.fileAssociations` for `.md`, `.markdown`
- Rust: listen `RunEvent::Opened` in `run()`, emit `"file-opened"` event to webview
- Frontend: listen `"file-opened"` event via `@tauri-apps/api/event`, call `loadFile()`
- On cold start: also check CLI args via `window.__TAURI_INTERNALS__` or `os.args()`

## 2. Startup Speed Optimization

**Approach:**
- Code splitting in `vite.config.ts`: split milkdown, lucide, react into separate chunks
- Remove React StrictMode for production builds
- Replace editor readiness polling (100ms interval) with event-based detection

## 3. Icon Update

- Source: `marknote_v1.2_fix.png` (1024x1024)
- Run `npx @tauri-apps/cli icon` to regenerate all sizes
- Update version references in `tauri.conf.json` and `package.json`

## 4. Auto-Save (3 min interval)

- `useEffect` + `setInterval` in `App.tsx`, every 3 minutes
- Only saves when `isDirty === true && filePath !== null`
- Silent save (no dialog for new untitled files)
- Clear dirty state on successful save

## 5. Word Count (bottom-right status bar)

- New `StatusBar` component at bottom of editor area
- Count: characters (all) + words (space-delimited for English, CJK chars count individually)
- Display: "字符: N | 词数: N"
- 300ms debounce on content change
- Semi-transparent background, 13px text, right-aligned

## 6. Export HTML / PDF

- **HTML export**: Rust command `export_html` — receives markdown + CSS, generates complete HTML file, saves via dialog
- **PDF export**: Open new window with read-only rendered HTML, call `window.print()` — user saves as PDF from browser dialog
- Toolbar: add export dropdown button with "Export HTML" and "Export PDF" options

## 7. Sidebar (File List / Recent Files)

- New `Sidebar` component, collapsible left panel (240px wide)
- Toggle button in toolbar (leftmost position)
- Two tabs: "当前目录" / "最近文件"
- Rust commands:
  - `list_dir_files(dir_path)` → list .md files in directory
  - `get_recent_files()` → read recent.json from app data dir
  - `add_recent_file(path)` → append to recent.json (max 20 entries)
- Click file item → `loadFile()` in current window

## Implementation Order

1. File association fix (fundamental, others depend on file loading)
2. Auto-save (simple, low risk)
3. Word count (simple UI addition)
4. Export HTML/PDF (new Rust commands + UI)
5. Sidebar (largest new component)
6. Startup optimization (needs all features stable first)
7. Icon update (last, cosmetic)
