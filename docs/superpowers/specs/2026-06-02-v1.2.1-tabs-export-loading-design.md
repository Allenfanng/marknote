# v1.2.1 改进设计

## 概述

三个改进项：浏览器式标签页、导出按钮修复、启动加载状态。

## 一、标签页

### 数据模型

```typescript
interface Tab {
  id: string              // 自增计数器，如 "tab-1"
  filePath: string | null
  content: string         // 当前 markdown 内容
  sourceContent: string   // 源码模式内容
  isDirty: boolean
  viewMode: 'wysiwyg' | 'source'
  editorKey: number       // 切换时递增，触发编辑器重建
}
```

### 状态管理

- 新增 `tabs: Tab[]`、`activeTabId: string`
- 移除顶层 `filePath, content, isDirty, sourceContent, viewMode, editorKey`
- 所有操作通过 `activeTab` 派生：`const activeTab = tabs.find(t => t.id === activeTabId)`

### 切换标签流程

1. 保存当前编辑器内容到当前标签：`activeTab.content = editorRef.current?.getMarkdown()`
2. 切换 `activeTabId`
3. 活动标签变化 → `editorKey` 已在 Tab 对象中，编辑器用新 key 重建

### TabBar 组件

替代现有 TitleBar。

布局：`[Tab1 ✕] [Tab2 ✕] [+]          [源码切换] [主题切换]`

- 整行可拖拽移动窗口（`-webkit-app-region: drag`），按钮区域 `no-drag`
- 活动标签底色与编辑区一致，非活动标签略灰
- 标签内容：文件名（或 "Untitled"）+ 脏标记（蓝点）+ 关闭按钮（hover 时显示）
- 标签过多时水平滚动，不换行

### 关闭逻辑

- 关闭有修改的标签 → 弹出确认（保存/不保存/取消）
- 关闭最后一个标签 → 自动新建 Untitled 标签

### 文件打开行为

所有文件打开操作统一为新开标签页：

- 拖拽文件 → 当前窗口新开标签页
- Ctrl+O → 新开标签页
- Ctrl+N → 新开标签页
- 侧边栏点击文件 → 如果已在某标签打开则切换，否则新开
- file-opened 事件 → 新开标签页
- 拖拽覆盖层文字改为 "Drop to open in new tab"
- 移除 `openFileInNewWindow` 函数和 `WebviewWindow` 导入

## 二、导出按钮修复

**根因**：`.toolbar` 的 `overflow-x: auto` 裁剪了绝对定位的 `.export-menu`。

**修复**：`.toolbar` 改为 `overflow: visible`。toolbar 按钮均有 `flex-shrink: 0`，不会溢出，滚动条本无必要。

## 三、启动加载状态

**根因**：Milkdown 初始化 1-3 秒，期间编辑区空白。

**修复**：
- `editorReady` 为 false 且 `viewMode === 'wysiwyg'` 时，显示加载占位
- 占位内容：居中 CSS spinner + "Loading..." 文字，匹配当前主题
- 编辑器就绪后自动切换到真实内容
- 不引入新依赖，纯 CSS spinner
